# Introduction

:::note
La documentation de la librairie Arduino est en cours de rédaction.
:::

La librairie Arduino d'Eliobot permet de programmer le robot en utilisant l'environnement Arduino IDE.

## Prérequis

- [Arduino IDE](https://www.arduino.cc/en/software) installé sur ton ordinateur
- La librairie Eliobot installée via le gestionnaire de bibliothèques Arduino
